# Topin prototypes (Indigo theme)

Clickable prototypes built with Wavekit design system tokens, in the indigo theme.

- `index.html` - Published Assessment: Basic Details, Sections Details and Advanced Options tabs, Invite Candidates panel, Statistics page with a 150-candidate example table, search popup, expandable left navigation.
- `system-check.html` - Candidate System Check screen shown before an assessment, with a working speed test.

Open the files in a browser, or view them on GitHub Pages. Candidate, section and settings data are examples.
