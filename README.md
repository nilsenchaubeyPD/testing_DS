# Published Assessment Prototype

Clickable prototype of the Topin Published Assessment page, built with Wavekit design system tokens and icons (Topin-Tech theme).

- Basic Details, Sections Details and Advanced Options tabs
- Invite Candidates side panel
- Statistics page with a 150-candidate example table
- Expandable left navigation

Open `index.html` in a browser, or view it on GitHub Pages. Candidate, section and settings data are examples.
