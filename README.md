# Topin prototypes (Sage & Ink)

Clickable HTML prototypes for the Topin Config Portal and Assessment Portal, styled with the **Sage & Ink** palette on Wavekit components, Manrope and Untitled UI icons.

Open `index.html` in a browser (no build step).

## Config Portal (`config-portal.html`)
- `config/assessment-details.html`: published assessment (Basic Details, Sections Details, Advanced Options), sidebar with search, invite drawer, candidate panel
- `config/assessment-details.html#statistics`: statistics with KPI cards and the candidate table

## Assessment Portal (`assessment-portal.html`)
- `assessment/system-check.html`: device and network checks before the test
- `assessment/mcq.html`: MCQ question screen with question palette, footer actions and A to D / Enter / M keyboard shortcuts
- `assessment/coding.html`: coding screen with description, editor, test cases console and resizable panes
- `assessment/feedback.html`: post-assessment rating and feedback

## Palette
Ink `#1C1917` for actions (hover `#44403C`), warm graphite neutrals, sage `#6E9A7C` only for progress and accents, sage tints `#F2F7F4` / `#C3D9CB` for selected states and focus. Light sage sidebar `#F7FAF8`. White backgrounds only. Minimum width 1024px.
